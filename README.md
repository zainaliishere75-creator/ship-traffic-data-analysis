# 🚢 Ship Traffic Analysis - Global Shipping Data

### Quranic Inspiration
> "And to Him belong the ships with elevated sails in the sea like mountains." - Surah Ar-Rahman 24-25

## 📊 Project Overview
Analyzed global shipping traffic to find busiest ports, ship types, and trade patterns. This project connects maritime interest with Data Analytics skills.

## 🛠️ Tools Used
- Python (Pandas, NumPy)
- Matplotlib & Seaborn for visualization
- GitHub for portfolio

## 🔍 Key Goals
- Find busiest shipping routes
- Analyze ship types: Container, Tanker, Bulk Carrier
- Show traffic trend by month
